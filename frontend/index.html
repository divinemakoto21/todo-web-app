Architecture Blueprint

FastAPI & SQLite Integration Contract

This frontend is decoupled from data persistence in strict compliance with project guidelines. All actions are dispatched through js/api.js, designed to connect to the following REST endpoints when FastAPI is started:

GET /api/tasks Fetch list of tasks with priority and due date
POST /api/tasks Create a new task with JSON payload
PUT /api/tasks/{id} Update task fields or toggle completion status
DELETE /api/tasks/{id} Remove task from SQLite database
GET /api/health Backend connection status & database readiness

Proposed SQLite Schema:

CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title VARCHAR(120) NOT NULL,
    description TEXT,
    priority VARCHAR(10) DEFAULT 'medium',
    due_date DATE,
    is_completed BOOLEAN DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
